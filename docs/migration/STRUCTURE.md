# JS9 Structure Baseline

This file tracks layout cleanup for the browser-only migration target.

## Current Rule

- Browser runtime files under `node/browser/` are the active source of truth.
- Root compatibility files are kept only for browser runtime loading.
- CLI/helper/server scripting entrypoints are out of active layout scope.

## Current Layout

- `node/browser/`:
  - `viewer.js` (viewer core source of truth, JavaScript during transition)
  - `worker.ts` (worker source of truth)
  - `worker.js` (generated by TypeScript build)
  - `postMessage.js` (browser module source)
  - `core/basicUtils.js` (extracted pure utility helpers)

- Root browser compatibility wrappers/symlinks:
  - `js9.js` symlinks to `node/browser/viewer.js`
  - `js9worker.js` symlinks to `node/browser/worker.js`
  - `js9PostMessage.js` symlinks to `node/browser/postMessage.js`

## Next Candidate Moves

- Expand extracted browser-core utility blocks under `node/browser/core/`.
- Continue reducing legacy build artifacts as Vite/browser packaging becomes canonical.
